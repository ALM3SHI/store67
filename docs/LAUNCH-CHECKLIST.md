# قائمة ما قبل الإطلاق

تظهر نسخة حية من هذه القائمة في لوحة التحكم (نظرة عامة → جاهزية الإطلاق).

## يتطلب حسابات أو موافقات خارجية (لا يمكن إنجازها من الكود)
- [ ] **السجل التجاري** أو وثيقة العمل الحر المناسبة لنشاطك.
- [ ] **توثيق المتجر الإلكتروني** لدى المركز السعودي للأعمال (منصة «توثيق» / معروف سابقًا) — تحقّق من المتطلب الحالي.
- [ ] **التسجيل في ضريبة القيمة المضافة** إن تجاوزت إيراداتك حد التسجيل الإلزامي، ثم فعّل الضريبة في الإعدادات. ملاحظة: إصدار **الفاتورة الإلكترونية (فاتورة/ZATCA)** للمسجلين في الضريبة غير مضمّن في هذا المشروع ويحتاج حلًا معتمدًا.
- [ ] **حساب تاجر Moyasar** معتمد (يتطلب السجل التجاري وحسابًا بنكيًا باسم المنشأة)، وتفعيل مدى وApple Pay وSTC Pay.
- [ ] **حساب أرامكس تجاري** مع بيانات API (أو اتفاق مع شركة شحن أخرى وإدخال التتبع يدويًا).
- [ ] **نطاق** (.sa أو .com) وحساب استضافة (Vercel) وقاعدة بيانات (Supabase).
- [ ] حسابات Google Search Console / Merchant Center / Analytics (اختياري).
- [ ] مراجعة قانونية لنصوص السياسات (الخصوصية، الشروط، الاسترجاع) بما يتوافق مع نظام التجارة الإلكترونية ونظام حماية البيانات الشخصية.

## داخل لوحة التحكم
- [ ] استبدال الصور التوضيحية بصور المنتج الحقيقي (المنتجات → الصور).
- [ ] توثيق المواصفات من المصنّع وتحديد «موثقة» لكل بند، أو حذفه. (غير الموثقة لا تظهر في الإنتاج.)
- [ ] إدخال سياسة الضمان إن وُجدت.
- [ ] تأكيد السعر (149 ر.س قيمة أولية) والمخزون الفعلي.
- [ ] سعر الشحن (25 ر.س قيمة أولية)، حد الشحن المجاني، مدة التوصيل الفعلية.
- [ ] مدة الاسترجاع (7 أيام قيمة أولية — راجعها مع نظام التجارة الإلكترونية).
- [ ] مراجعة كل صفحة سياسة وتحديد «تمت المراجعة».
- [ ] إدخال الوثائق التجارية وأرقامها وتواريخ انتهائها، واختيار ما يظهر للعملاء.
- [ ] بيانات التواصل وواتساب وروابط الحسابات.
- [ ] التصنيفات (لوحة التحكم → التصنيفات) بأسماء نهائية.
- [ ] أسعار الشحن الخاصة ببعض المدن (إن وُجدت) في الإعدادات → الشحن.
- [ ] تفعيل الدفع عند الاستلام إن أردته، ورسومه وحدّه الأعلى.
- [ ] تأكيدات «ما قبل الإطلاق» في الإعدادات.
- [ ] إنشاء حسابات الموظفين بالأدوار المناسبة، وتغيير كلمة مرور المالك.

## تقني
- [ ] `APP_ENV=production` و`APP_URL=https://...` و`SESSION_SECRET` عشوائي طويل.
- [ ] `DATABASE_URL` على Postgres مُدار + نسخ احتياطي مجدول + تجربة استعادة.
- [ ] `STORAGE_DRIVER=supabase` (أو قرص دائم).
- [ ] عدم وجود `PAYMENTS_TEST_GATEWAY` في الإنتاج.
- [ ] Webhook Moyasar الحي مضبوط ومجرّب، ومعاملة حقيقية صغيرة + استرجاعها.
- [ ] `CRON_SECRET` مضبوط ومهمة انتهاء الطلبات تعمل.
- [ ] بريد Resend مهيأ بنطاق موثّق (`RESEND_API_KEY`, `EMAIL_FROM`) وطلب تجريبي يصل بريده.
- [ ] تنبيهات تيليجرام أو بريد الفريق تعمل («إرسال تنبيه تجريبي» في الإعدادات).
- [ ] مراقبة توفّر خارجية على `/api/health`.
- [ ] تجربة «نسيت كلمة المرور» مرة واحدة على الإنتاج.
- [ ] التحقق بخطوتين مفعّل لكل حسابات الإدارة، ورموز الاسترداد محفوظة.
- [ ] (اختياري) الرسائل النصية: اسم مرسل معتمد في تقنيات + رسالة تجريبية وصلت.
- [ ] `npm run check` و`npm run test:e2e` ناجحة على آخر نسخة.
- [ ] فحص الصفحة بـ PageSpeed Insights على الجوال بعد رفع الصور الحقيقية.
